# Lilbot Pro Customer Terms

This is a practical customer-terms template for the first paid Lilbot Pro launch. Have a lawyer review it before high-volume sales or enterprise deals.

## Product

Lilbot Pro is a local-first command line product for developer-tool maintainers. Pro unlocks repository product-readiness audits, launch-pack generation, and related local workflows.

## License

Each paid seat may activate Lilbot Pro for one human user. The customer may use Lilbot Pro on multiple machines they personally operate, as long as the license is not shared with other users.

## Source Code and Data

Lilbot is designed to run locally. The Pro audit and launch-pack workflows inspect files under the configured workspace root and do not require sending source code to a hosted Lilbot service.

## Support

Pro customers receive setup and activation support by email. Include this output when reporting an issue:

```bash
lilbot --version
lilbot doctor
lilbot license status
```

## Refunds

Offer a 14-day refund for first-time Pro purchases when the customer cannot activate the product or the Pro workflow does not run in their supported environment.

## Updates

Pro customers receive updates published through the same package distribution channel they used to install Lilbot.

## Limitations

Lilbot Pro produces technical and product-readiness guidance. It does not guarantee revenue, investment, legal compliance, security compliance, or marketplace approval.

## Abuse

License sharing, resale of license keys, attempts to bypass entitlement checks, or use of Lilbot to operate outside configured safety boundaries may result in license cancellation.
